# Add a fluent api
```groovy
Gmd gmd = new Gmd()
def outputDir = new File("build")
def htmlFile = new File(outputDir, "whiskeyAnalysis.html")
def gmdFile = new File("src/main/gmd/WhiskeyAnalysis.gmd")
gmd.gmdToHtml(gmdFile.text, htmlFile, [:])
```

Consider adding a fluent api e.g:

```groovy
Gmd.builder()
  .input("src/main/gmd/WhiskeyAnalysis.gmd")
  .output("build/whiskeyAnalysis.html")
  .gmdToHtml()

// also support File (and Path)
Gmd.builder()
  .input(new File("src/main/gmd/WhiskeyAnalysis.gmd"))
  .output(new File("build/whiskeyAnalysis.html"))
  .gmdToHtml()

Gmd.builder()
    .input(Paths.get("src/main/gmd/WhiskeyAnalysis.gmd"))
    .output(Paths.get("build/whiskeyAnalysis.html"))
    .gmdToHtml()

// as well as PDF's (add overloads for File and Path similar to above)
Gmd.builder()
    .input("src/main/gmd/WhiskeyAnalysis.gmd")
    .output("build/whiskeyAnalysis.pdf")
    .gmdToPdf()
```
